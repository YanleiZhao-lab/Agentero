# AgenteroZ 定制自用版实施计划

**目标：** 将科研分支的可见名称、图标、项目链接及功能说明统一为 AgenteroZ 定制自用版，保留现有安装识别、数据目录和上游自动同步。

**实现：** 前端品牌信息由 `research-channel.json` 提供；原生窗口、安装器显示信息、更新渠道和发布资产沿现有 Tauri/NSIS/Research channel 入口调整。安装识别用的 `productName`、应用 identifier、程序文件名、Vault 和用户目录保持现有值。

## 1. 品牌与界面

- [x] 在 `research-channel.json` 增加确认过的显示名称。
- [x] 新增书页、声波和 Z 组成的深蓝色 SVG 图标，并由 Tauri CLI 生成原生图标。
- [x] 统一关于、欢迎、移动端品牌和导出标记的名称、图标与项目链接。
- [x] 关于页面列出多文档笔记选择、按论文记忆选择、科研技能及自动跟进上游的说明，保留上游署名；反馈入口转到 Fork Issues。

## 2. 安装与更新

- [x] Tauri 窗口标题及新增窗口使用品牌显示名称。
- [x] NSIS 沿用现有卸载注册表键与路径，只更新显示名和自己持有的快捷方式；卸载同步清理品牌快捷方式。
- [x] 更新包、CLI 下载、版本详情及更新记录均指向 Fork。
- [x] 科研构建生成对应版本的中英更新记录并将其作为校验资产发布。
- [x] 保留原有上游稳定版筛选、定时触发、合并冲突处理、签名、发布验证和分支推进机制。

## 3. 验证与交付

- [x] 运行类型检查、依赖边界检查、相关前端用例及构建。
- [x] 使用隔离的临时配置验证版本生成、更新源、签名公钥、更新记录与交付资产清单。
- [x] 检查实际界面渲染及图标大小下的可读性，不写入真实 Vault 或用户设置。
- [x] 通读组合差异，提交到 `codex/agenteroz-branding`，记录验证结果。
- [x] 发布和安装仍按当前授权范围处理；未执行的操作如实注明。

## 验证结果

- TypeScript、依赖边界、前端生产构建及原生代码检查通过。
- 使用 CI 同系列的 Node 24 运行全量前端测试：3506 项通过，5 项为原有跳过项。本机 Node 26 的浏览器存储差异造成的失败，已在 Node 24 环境复测解决。
- 无界面浏览器检查中文、英文及较窄窗口的实际渲染；点击验证 Fork 项目、Issues 和明确标注的上游署名链接。
- 使用 Tauri 对应版本的 NSIS 编译器编译安装/卸载钩子，无警告。
- 隔离配置、双语更新记录、历史保留与去重、交付清单及损坏检测通过；真实 Git 合并验证了吸收上游修改并保留定制和工作流。
- 使用既有 1.5.1 签名包测试新文件名和八项发布资产，重命名后的负载及受信注释签名仍通过。该夹具不是新版本安装包。
